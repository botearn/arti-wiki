# ARTI 输出模板汇总（详细版）

> Multi-Agent 系统各层输出模板、评分规则、红旗信号、辩论角色、HTML 章节结构。
> 来源：`supabase/functions/_shared/prompts/`、`scripts/report-worker/`、`benchmark/schema/`。
> **核心设计**：LLM 只在契约内填字段；计算、排版、章节顺序由代码模板控制。

---

## 零、系统级通用规则（所有 Agent 共用）

所有 prompt 末尾注入以下两段（`_shared/prompts/common.ts`）：

### COMPUTE_PRINCIPLE · 计算与解读分工
- 职责是"解读"，不是"计算"
- 所有技术指标（均线/RSI/MACD/ATR/BB）已由系统脚本预计算，以结构化数据注入
- 直接引用系统数据，不自行计算
- 系统未提供的数据标注"暂无数据"

### DATA_ANNOTATION_RULE · 数据准确性铁律
- 严禁凭记忆编造价格、涨跌幅
- 严禁编造公司主营信息
- 直接引用系统数据，不加 `[数据]`/`[推断]` 标签
- 报告末尾必附免责声明

### NO_COMPETITOR · 竞品禁令与客观性
- 不得提及具体券商/行情软件/数据终端名称
- 不得使用"仙股/妖股/割韭菜/跳水"等情绪化或贬义标签
- 不得给具体目标价位断言
- 多空并陈，区分事实与观点

```
  - 对 Steve（板块轮动）：重点关注XX板块 / 回避XX板块
```

| 5-6 | 震荡：多空交织 | 20-30% |
| 3-4 | 偏空：多数信号负面 | 10-20% |

### 3. Tony 🦾 · Morgan Stanley 技术策略师（AVPR 框架）

**Phase 2（并行）** · 核心：确认技术形态，给出可执行进出场计划

```

  - MA20：XX，当前价格在 MA20 上方/下方
  - ATR(14)止损参考：XX（建议止损 = 2×ATR）

▌AVPR信号：
  - 涨停板动能：X板（弱/中/强）
  - 量价关系：量比XX，价X量X（健康/异常/背离）
  - 均线共振：XX均线金叉/死叉 + 排列状态
  - 综合AVPR信号：强做多 / 做多 / 中性 / 做空 / 强做空

▌交易计划：
  - 方向：做多 / 做空 / 观望
  - 进场价位：XX（触发条件：...）
  - 止损价位：XX（基于 2×ATR = XX）
  - 目标价位1：XX（风险回报比 1:X）
  - 目标价位2：XX
  - 风险回报比：1:X
```

**AVPR 框架细节**
- **涨停板动能**：1 板=弱｜2-3 板=中｜≥4 板=强
- **均线体系**：MA5>MA10>MA20>MA60=多头排列｜金叉=买｜死叉=卖
- **成交量**：量比>1.5 活跃｜>3.0 放量｜价涨量增=健康｜价涨量缩=乏力｜价跌量增=恐慌

**信号矩阵**
- 连板(≥2) + 高开 + 多头排列 + 量比>2x = 强做多
- 单板 + 金叉 + 量比 1.5-2x = 做多
- 无涨停 + 均线纠缠 + 量比<1 = 中性
- 无涨停 + 死叉 + 放量下跌 = 卖出
- 跌停 + 空头排列 + 量比>3x = 强做空

**红旗信号（触发任一，交易计划必改为观望/卖出）**
- MA5/MA10 死叉 + 放量下跌（量比>2x）
- 量比 > 5x 且位于高位（异常放量，可能主力出货）
- 连板股开板 + 量比 > 3x（龙头断裂）
- RSI > 85 + 触及 BB 上轨 + 量缩（动能衰竭）

**1. 价值因子（权重 20%）**

- ROE：>20%=10 ｜15-20=8 ｜10-15=6 ｜5-10=4 ｜<5=2
- ROA：>10=10 ｜7-10=8 ｜4-7=6 ｜2-4=4 ｜<2=2
- 毛利率：>50=10 ｜30-50=7 ｜15-30=5 ｜<15=3
- 商誉占比：<10=10 ｜10-20=7 ｜20-30=4 ｜>30=2
- 质量因子 = 四项平均

**3. 动量因子（权重 20%）**

**5. 情绪因子（权重 15%）**

### 1. Buffett · 价值守门人（立论）

**角色锚定**

**分析要求**
1. 护城河分析：类型（品牌/网络效应/转换成本/规模/专利）、深度 1-5、趋势

4. 长期持有逻辑与安全边际


## 七、设计原则

1. **数据是锚**：prompt 绝不编造数字，系统未提供就标注"暂无数据"
2. **Prompt 是方法论**：投行/对冲基金方法论（AVPR / AQ7 / HEX6 / EAG / F5Q / CAPS / RTP-STM / RCM）硬编码进 prompt
3. **编排是视角**：Layer 1 给事实、Layer 2 辩观点、Synthesizer 裁分歧
4. **Schema 是契约**：三层输出必过 JSON Schema，违规不渲染
5. **模板是骨架**：HTML 章节顺序由代码固定，LLM 只填字段
6. **红旗是熔断**：任一红旗触发即强制评级/仓位，绕过其他信号
7. **依赖是硬链**：Thor 仓位上限 > Wanda 组合｜Natasha 评分 → Thor 仓位映射不可绕过

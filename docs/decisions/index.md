# 决策记录

本目录记录 ARTI 项目中所有重要的产品与技术决策。

## 为什么要记录决策？

- 避免"当时为什么这么做"的重复讨论
- 让新成员快速理解背景
- 追踪决策的演变过程
- 明确每个决策的责任人

## 如何新增决策记录

1. 复制以下模板
2. 文件命名：`YYYY-MM-DD-简短描述.md`
3. 提交 PR，标签添加 `type:decision`
4. 相关人员 Review 后合并

## 决策模板

```markdown
# 决策：[决策标题]

**日期**：YYYY-MM-DD  
**决策人**：[姓名]  
**状态**：草稿 / 评审中 / 已确认 / 已废弃  

## 背景

[为什么需要做这个决策？当时面临什么问题或情况？]

## 考虑的方案

### 方案 A：[名称]
- 优点：
- 缺点：

### 方案 B：[名称]
- 优点：
- 缺点：

## 决策内容

[最终选择了什么方案，以及核心理由]

## 影响

[这个决策对团队、产品、代码库有什么影响？需要哪些跟进动作？]

## 相关链接

- Issue：#
- PRD：
```

## 状态说明

- **草稿**：决策尚未最终确认
- **评审中**：等待相关人员确认
- **已确认**：正式生效
- **已废弃**：因情况变化，此决策不再适用

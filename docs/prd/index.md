## 状态说明

- **草稿**：内容尚未最终确认，可能大幅修改
- **迁移中**：原文档在飞书，正在迁移到本仓库
- **评审中**：内容已完成，等待团队评审
- **已确认**：团队已对齐，可作为开发依据
- **已归档**：功能已上线或废弃，仅供参考

## 如何新增 PRD

1. 复制 [PRD 模板](../guides/prd-template.md)
2. 在本目录创建新文件，命名规则：`功能名称-kebab-case.md`
3. 提交 PR，标签添加 `type:prd-clarification`
4. 至少一名产品成员 Review 后合并

## 注意事项

- PRD 修改必须走 PR 流程，禁止直接推送到 main
- PRD 中的重大变更需在对应 Issue 中通知相关开发人员
- 飞书中讨论的 PRD 修改结论，**当天**必须同步到对应文档
